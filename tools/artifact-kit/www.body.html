The Internet and the World Wide Web

The internet is the network; the web is one service that runs on it. URLs, DNS, HTTP and HTTPS, cookies and how a page reaches your screen.

The core idea

The internet is the network. The World Wide Web is one service that runs on it. When you type a web address, your browser uses the internet to ask a web server for a page, and DNS is what turns the name you typed into an address the network can use.

1 · Internet versus WWW

The internet

A huge worldwide network made of many smaller networks joined together. It is the hardware and connections: cables, routers, servers, satellites. It carries data for lots of services.

The World Wide Web

A collection of web pages and other resources stored on web servers. You reach them with a web browser, using URLs and the HTTP or HTTPS protocol. Pages are written in HTML.

Example. Email, video calls (VoIP) and online games all use the internet, but they are not the web. Reading a news site in Chrome is the web. Think of the internet as the road network and the web as one of the things that drives along it.

2 · URL, tap each part
://

A URL (Uniform Resource Locator) is the full address of one resource on the web. A domain name is the human-friendly name of the website's host. A web page name or file name is the specific page.

3 · HTML

HyperText Markup Language is the code a page is written in. It describes the structure and content: headings, paragraphs, images, links. CSS handles how it looks. The browser reads the HTML and renders it as the page you see.

<h1>Trainers</h1>
<p>New stock in.</p>

4 · Web browser

Software that requests web pages and renders HTML so a person can read them. Typical functions:

  • renders HTML and shows the page
  • address bar to enter a URL
  • stores bookmarks, history and cookies
  • tabs, back and forward buttons
  • can store saved passwords and form data
5 · HTTP and HTTPS

HTTP (HyperText Transfer Protocol) is the set of rules browsers and web servers use to request and send pages. Data sent this way is not encrypted, so anyone intercepting it can read it.

HTTPS is HTTP with encryption added, using SSL/TLS. The server proves who it is with a digital certificate, and the data travelling between browser and server is scrambled. The browser shows a padlock.

Example. A card number typed into a shop's checkout is encrypted on the way, so someone capturing the traffic sees gibberish.

6 · IP addresses and DNS

Every device on a network has an IP address, a unique number that lets data be sent to the right place. Web servers have one too. People remember names, not numbers, so the Domain Name System (DNS) translates the domain name into an IP address.

IPv4

192.168.1.10

32 bits, four numbers 0 to 255. About 4.3 billion addresses, which ran short.

IPv6

2001:0db8:85a3:0000:0000:8a2e:0370:7334

128 bits, written in hexadecimal. Far more addresses.

How DNS resolves a URL
  1. Browser sends the domain name to a DNS serverFor example www.school-shoes.com.
  2. DNS server looks it up in its databaseIf it does not have the record, it passes the request on to another DNS server.
  3. The IP address is returned to the browserIf no record exists anywhere, an error such as "server not found" is shown.
  4. Browser contacts the web server at that IP addressIt requests the page using HTTP or HTTPS.
7 · Web server

A computer that stores websites and sends pages to browsers on request. It listens for HTTP or HTTPS requests, finds the page, and sends it back. It can also create cookies and store user account data.

8 · Cookies

A cookie is a small text file a website's server creates and the browser stores on the user's device. It holds data such as an ID, preferences or basket contents. On later visits the browser sends it back so the site can recognise the user. Cookies are just data. They are not programs and cannot run or spread like a virus.

Uses: saving login details, holding a shopping basket, remembering preferences, and recording browsing habits so a site can show targeted adverts. Concern: tracking cookies build a picture of what a person does online, which is a privacy issue.

9 · Digital currency

Money that exists only in electronic form, with no coins or notes. Some digital currency is controlled by a central body such as a bank. Cryptocurrencies like Bitcoin are decentralised: no single bank or government controls them, and transactions are checked and recorded by a network of computers. Cryptocurrency uses encryption and a blockchain to record who owns what.

Blockchain: why tampering shows

A blockchain is a digital ledger split into linked blocks. Each block holds transaction data, a timestamp, its own hash and the hash of the block before it. A hash is a fixed-length code worked out from the block's contents, so changing any data changes the hash.

Try it: edit a transaction

Demo hash only, a simple stand-in for the real thing (real blockchains use SHA-256). The point is the behaviour: alter block 2 and block 3's stored "previous hash" no longer matches.

Why it is hard to cheat

To hide a change, an attacker would have to recalculate every later block. And copies of the chain are held by many computers, so the altered version would not match the others.

Where it is used

Recording cryptocurrency transactions. It can also record other data that must not be changed later, such as ownership records.

Match the term to its meaning

Multiple choice

Examples are explained in general terms.

Online shopping

You type a shop's address, DNS finds its server, and the page loads. At checkout, HTTPS encrypts your card number on the way. The shop's server also stores a cookie to remember what is in your basket.

Use it for: HTTPS, cookies and the DNS sequence in one example.

Email and video calls

These use the internet but do not use web pages and a browser in the same way. They show that the internet and the web are not the same thing.

Use it for: the difference between internet and web.

"Remember me" on a website

The site creates a persistent cookie that stays on your computer after you close the browser, so it can recognise you next time.

Use it for: session versus persistent cookies.

The padlock in the address bar

The padlock shows that the connection is encrypted with TLS and the site has a digital certificate. It does not prove that the site is honest.

Use it for: saying "encrypted", not "safe".

Exam-style questions

Written in the style, wording and mark allocations of Cambridge 0478 Paper 1, and marked with point-based schemes like the real ones. They are practice questions, not copied past-paper items. Try each before opening the answer.

Question 1[2 marks]

Give two differences between the internet and the World Wide Web.

Mark scheme and explainer
  • The internet is the global network of networks / the infrastructure; the WWW is a collection of web pages and websites
  • The WWW is accessed using a web browser; the internet can be used without one
  • The WWW uses URLs and HTTP/HTTPS and is written in HTML; the internet also carries email, VoIP, file transfer
  • The WWW runs on top of / is a service using the internet
Examiner view. You need two contrasting statements, each about a different thing. "The internet is bigger" gains nothing. Say what each one is.
Question 2[4 marks]

The URL https://www.school-shoes.com/shop/trainers.html is entered into a web browser. Identify the protocol, the domain name, the path and the web page name.

Mark scheme and explainer
  • Protocol: https
  • Domain name: www.school-shoes.com
  • Path: /shop
  • Web page name (file): trainers.html
Examiner view. One mark each. Do not include :// or slashes in the protocol and page name. A frequent slip is calling .com the domain name: it is only the top-level part.
Question 3[3 marks]

Describe how the Domain Name System (DNS) is used to find a website when a URL is entered.

Mark scheme and explainer
  • The browser sends the domain name / URL to a DNS server
  • The DNS server looks up the domain name in its database and finds the matching IP address
  • If not found, the request is passed on to another DNS server
  • The IP address is sent back to the browser, which uses it to contact the web server
Examiner view. The answer is a translation from name to IP address. Do not say DNS "finds the web page" or "sends the page". The web server does that.
Question 4[2 marks]

State two differences between a session cookie and a persistent cookie.

Mark scheme and explainer
  • A session cookie is deleted when the browser is closed; a persistent cookie stays until it expires or the user deletes it
  • A session cookie is held in temporary memory; a persistent cookie is stored on the device's storage
  • Session cookies suit a shopping basket or single visit; persistent cookies suit remembered logins or preferences
Examiner view. Write the answer as "session: X, persistent: Y". Saying only "one lasts longer" is too vague.
Question 5[4 marks]

A customer visits an online shop for the first time, leaves, and later returns. Describe how the shop's web server uses a cookie to recognise the customer on the second visit.

Mark scheme and explainer
  • On the first visit the web server creates a cookie containing data such as a customer ID
  • The cookie is sent to the browser and stored on the customer's device
  • On the return visit the browser sends the stored cookie to the web server with its request
  • The server reads the cookie, recognises the customer, and can load their saved details / preferences / basket
Examiner view. This is the flowchart above written as prose. Four marks means four separate steps, in order. Say who does each thing (server creates, browser stores, browser sends back, server reads).
Question 6[3 marks]

Explain why a bank's website uses HTTPS rather than HTTP.

Mark scheme and explainer
  • HTTPS encrypts the data sent between the browser and the web server (using SSL/TLS)
  • So if the data is intercepted, it cannot be read / understood
  • Customers' login and account details are therefore protected
  • (Also accepted) HTTPS uses a digital certificate to show the site is genuine
Examiner view. "It is more secure" earns nothing on its own. The mark is the word encrypted, followed by the consequence: intercepted data is unreadable.
Question 7[2 marks]

Give two reasons why a person types a domain name into a browser instead of an IP address.

Mark scheme and explainer
  • A domain name is easier to remember / type than a long number
  • A domain name is more meaningful and reflects the site's name
  • An IP address can change while the domain name stays the same
Examiner view. "Easier" needs a reason to be safe: easier to remember. Then mention DNS does the conversion in the background.
Question 8[4 marks]

Describe how a blockchain makes it difficult for someone to change a past transaction without being noticed.

Mark scheme and explainer
  • Each block stores a hash calculated from its own data
  • Each block also stores the hash of the previous block, linking them in a chain
  • If data in a block is altered, its hash changes
  • The next block's stored previous hash no longer matches, so the chain is broken / tampering is detected
  • The chain is copied on many computers, so the altered copy can be compared against the others
Examiner view. Take any four. The key chain of reasoning is: change data, so hash changes, so next block no longer matches. Use the words hash and previous block.
Question 9[2 marks]

A student says: "Cookies are viruses that copy themselves onto my computer." Explain why the student is wrong.

Mark scheme and explainer
  • A cookie is a small text file / data, not a program
  • It cannot run or replicate itself, or damage files
  • (Also accepted) it is created by a website the user visited, and only holds data such as preferences or an ID
Examiner view. Cookies do raise a privacy concern through tracking. That is different from being malware, and the question only asks about the second.

Top tips for the exam

Trap

Internet is not the web

Do not use the words as if they mean the same thing. Internet: the network. Web: pages reached through a browser. Email is internet, not web.

Trap

Cookies are not viruses

They are small text files holding data. They cannot run code. Say "text file" or "data", never "program".

Trap

HTTPS means encrypted, not "safe"

A padlock means the connection is encrypted. It does not prove the site is honest or free of malware. Use the word encrypted.

Trap

DNS returns an IP address

It does not fetch the page. The sequence is: name to DNS, IP back, browser contacts web server, page sent.

Match the command word

State/Give: short fact. Describe: what happens, in order. Explain: a point plus "because" or "so that". Marks are almost always one per point.

Say who does what

In cookie and DNS questions, name the actor in every sentence: the server creates, the browser stores and sends, the DNS server looks up.

Session versus persistent

Give the deletion rule for each: session ends when the browser closes, persistent stays until expiry or manual deletion. Add an example use.

Blockchain chain of reasoning

Data changes, so the hash changes, so the next block's previous-hash no longer matches. Then mention many copies on many computers.

Learn the URL parts by heart

Protocol, domain name, path, page name. Easy marks for labelling a URL, so practise splitting a few every week.

Use exact terms

Web server, web browser, domain name, IP address, HTML, SSL/TLS, hash. Vague words like "the computer" and "the internet thing" lose marks.
