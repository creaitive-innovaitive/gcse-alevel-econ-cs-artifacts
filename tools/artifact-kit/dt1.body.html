Types and Methods of Data Transmission

How data is split into packets and routed across a network, the five transmission modes (serial, parallel, simplex, half-duplex, full-duplex), and how USB moves data between a device and a computer.

The big idea

Data is rarely sent as one long stream. Over a network it is cut into small data packets, each sent independently and put back together at the other end (packet switching). Between two devices, the data can travel one bit at a time (serial) or several bits at once (parallel), and in one direction or both.

2.1.1 Data packets

A data packet is a small part of a message, typically about 64 KiB. Splitting data this way means each packet can take a different route, so a busy or broken line can be avoided. The only real drawback is that the packets must be reassembled at the destination.

Packet structure

Headersender IP · receiver IP · sequence number · packet size
Payloadthe actual data (about 64 KiB)
Trailerend marker · error check (CRC)

Header

The IP address of the sender and of the receiver, the sequence number (so packets can be put back in order) and the packet size (so the receiver can check each one arrived intact).

Payload

The actual data being carried by this packet.

Trailer

A way of identifying the end of the packet, and an error check: a cyclic redundancy check (CRC).

Cyclic redundancy check (CRC), as the course describes it

  1. The sender adds up all the 1-bits in the payload and stores the total, as a hex value, in the trailer.
  2. When the packet arrives, the receiver recalculates the number of 1-bits in the payload.
  3. It compares the new value with the one in the trailer.
  4. Match: no transmission error. No match: the packet is re-sent.

Real CRCs use a more advanced calculation. Use the 1-bit counting description in the exam.

Packet switching

Packet switching breaks a message into packets, and each packet is sent independently from start to finish. At each stage of the journey is a node containing a router. The router reads the destination IP address in the header and decides where to send the packet next.

  • Each packet follows its own path, chosen by the routers.
  • The route depends partly on how many packets are already waiting at each node.
  • Packets can arrive in a different order from the one they were sent in. The receiver uses the sequence numbers to reassemble them.

Benefits

  • No need to tie up a single communication line
  • Failed, busy or faulty lines can be avoided by re-routing packets
  • Easy to expand
  • A high data transmission rate is possible

Drawbacks

  • Packets can be lost and need to be re-sent
  • More prone to problems with real-time streaming, such as a live sports match
  • A delay at the destination while packets are reordered
Beyond the syllabus, but usefulTo stop lost packets bouncing around forever, each header can carry a hop number that goes down by 1 at every router. At 0 the packet is deleted, and the receiver asks for it to be re-sent. The course book says hopping is not on the syllabus.

Two separate questionsSerial/parallel is about how many bits at once. Simplex/half/full is about direction. Any serial or parallel link can also be simplex, half-duplex or full-duplex. Answers such as "serial, half-duplex" combine one from each.

2.1.3 Universal Serial Bus (USB)

USB is a form of serial data transmission and the most common type of input/output port. It is a standard way to connect devices to a computer, and it supports both half-duplex and full-duplex.

  • The cable has four wires: two for power (red +5 V and black ground) and two for data (white and green), plus a shield.
  • The computer detects a new device automatically (a small change in voltage on the data wires).
  • The device is recognised and its device driver is loaded. If the driver is missing, the user is prompted to download it.
  • USB-C is a newer 24-pin connector that fits either way round, is smaller, can carry power for charging, and supports fast data rates.

Benefits of USB

  • Devices are detected automatically and drivers load automatically
  • Connector fits only one way (standard type), so it cannot be plugged in wrongly
  • Industry standard, so wide support
  • Supports different transmission rates
  • Cable supplies +5 V, so no extra power supply is needed
  • The USB protocol asks for data to be re-sent if an error is found, so transfers are error-free
  • Easy to add more ports with a hub
  • Backward compatible

Drawbacks of USB

  • Standard cables support a maximum of about 5 m; longer needs hubs
  • Very early versions may not be supported by the newest computers
  • Data rates are slow compared with, for example, Ethernet

Loading a web page

A large web page is not sent as one lump. The server splits it into packets, routers send each one along the quickest working route, and your device puts them back in order using the sequence numbers.

Exam use: the standard example for "explain how packet switching could be used to download a large web page".

Video calls and live sport

When packets are delayed, lost or reordered, a video call can freeze, blur or lose sound. This is more noticeable for real-time streaming because there is no time to wait for lost packets to be re-sent.

Exam use: a drawback of packet switching: it can cause problems with real-time streaming.

A road network for data

Think of drivers who each take their own route to the same stadium. If one road is closed, others carry on. The drivers arrive in a different order from the one they left in, and the match cannot be reconstructed until all have arrived.

Exam use: an analogy for re-routing around busy or faulty lines, and for packets arriving out of order.

Walkie-talkies and phone calls

A walkie-talkie is half-duplex: you press to talk and release to listen. A normal phone call, or a broadband connection, is full-duplex: both sides can talk and be heard at the same time. Sending a document from a computer to a printer is simplex: data only goes one way.

Exam use: the three standard examples for the three directions of transmission.

USB sticks, keyboards and phone chargers

Plugging in a USB device makes the computer detect it, load the right driver and often power it from the cable. USB-C is now common on laptops and phones because the plug works either way round and can carry enough power to charge a laptop.

Exam use: benefits of USB: automatic detection, standard connector, power from the cable, cannot be plugged in the wrong way.

Inside the computer

Components on the motherboard are very close together, so parallel pathways can move many bits at once with little risk of skew. Over a long cable the bits would drift out of step, so long-distance links such as telephone lines use serial.

Exam use: why parallel suits short distances and serial suits long ones.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 Describe 3 marks Describe the contents of the header of a data packet.
ReminderName each item and, where you can, say what it is for.
The header contains the IP address of the sender and the IP address of the receiver. It contains the sequence (packet) number, so the packets can be reassembled in the correct order. It contains the size of the packet, so the receiver can check whether the packet arrived intact.
Common mistakePutting the CRC in the header. The error check is in the trailer.
Q2 Explain 4 marks Explain how packet switching could be used to download a large web page from a website.
ReminderFollow the journey: split, route, arrive, reassemble. Mention routers and sequence numbers.
The web page data is split into data packets, each with a header containing the destination IP address and a sequence number. Each packet is sent independently, and can take a different route. Routers along the way read the destination address and decide where to send each packet next. At the destination the packets may arrive out of order, so they are reassembled using the sequence numbers to display the page.
Common mistakeSaying "the packets all go the same way". The point of packet switching is that they do not have to.
Q3 Give 4 marks Give two benefits and two drawbacks of packet switching.
ReminderTwo of each. Keep them short and distinct.
Benefit: it does not tie up a single communication line. Benefit: packets can be re-routed around failed, busy or faulty lines. Drawback: packets can be lost, and need to be re-sent. Drawback: there is a delay at the destination while packets are reordered (and it can be less suitable for real-time streaming).
Common mistakeWriting "it is faster" and "it is slower" with no reason. Say why.
Q4 Describe 4 marks Describe how a cyclic redundancy check (CRC) is used to check a data packet.
ReminderSender calculates, stores in the trailer, receiver recalculates, compare, decide.
The sending computer adds up the 1-bits in the payload and stores the total (as a hex value) in the trailer. The packet is sent to the receiving computer. The receiving computer recalculates the number of 1-bits in the payload and compares it with the value in the trailer. If the values match, no transmission error has occurred; if they differ, the packet is re-sent.
Common mistakeForgetting that the receiver does its own calculation. Comparing needs two values.
Q5 State 3 marks A computer sends data to a printer. Another sends a message to a colleague on a video call. A user speaks on a walkie-talkie. State the transmission mode for each.
ReminderDirection only: one way, both ways in turn, or both ways together.
Computer to printer: simplex (one direction only). Video call: full-duplex (both directions at the same time). Walkie-talkie: half-duplex (both directions, but not at the same time).
Common mistakeMixing up half- and full-duplex. Half = take turns. Full = simultaneously.
Q6 Explain 4 marks A school sends data between two computers in the same room using a short cable, and between two schools over a long distance. Explain why parallel is better for one and serial for the other.
ReminderUse "skew" and "faster/slower". One reason per mode, linked to distance.
Parallel sends several bits at the same time down several wires, so it is faster. Over a short distance the bits are unlikely to arrive out of sync, so parallel is suitable. Over a long distance parallel data can become skewed (bits arrive out of order). Serial sends one bit at a time on a single wire, so the bits arrive in order and it is more reliable over long distances.
Common mistakeSaying parallel is "better" without conditions. The honest answer is that each suits a different distance.
Q7 Describe 3 marks Describe what happens when a USB device is plugged into a computer for the first time.
ReminderDetect, recognise and load the driver, or prompt for it.
The computer automatically detects that a device has been connected (a change in voltage on the data wires). The device is recognised, and the computer looks for the matching device driver. If the driver is already installed it is loaded; if not, the user is prompted to download it.
Common mistakeWriting "it works automatically" and stopping. Name the driver.
Q8 Give 4 marks Give two benefits and two drawbacks of using USB to connect devices.
ReminderPick distinct points. Cable length and speed are the usual drawbacks.
Benefit: devices are detected automatically and drivers are loaded automatically. Benefit: the cable supplies +5 V, so many devices need no separate power supply. Drawback: standard USB cables are limited to about 5 m. Drawback: the data transfer rate is slower than some other connections, such as Ethernet.
Common mistakeQuoting a "benefit" that is not specific to USB, such as "it is fast".

Top tips

  • Header, payload, trailer. Addresses and sequence number in the header, data in the payload, end marker and CRC in the trailer.
  • Packet switching answers need the chain: split, independent routes, routers read the destination address, arrive out of order, reassembled by sequence number.
  • Say who calculates the CRC. Sender stores it, receiver recalculates, then they compare.
  • Direction and method are separate. Simplex, half, full describe direction. Serial, parallel describe how many bits at once.
  • Half-duplex = take turns. Full-duplex = same time. Use walkie-talkie and phone call or broadband to remember.
  • Parallel is faster but skews over distance. Serial is slower but reliable over distance.
  • USB is serial. Four wires: two power, two data. Detects devices, loads drivers, about 5 m limit.
  • Benefit and drawback questions: give a different point for each mark, and make it specific.
