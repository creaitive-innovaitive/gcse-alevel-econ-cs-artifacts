The big idea

Computers find websites by IP address, but people use domain names. The Domain Name System (DNS) is the service that translates one into the other.

Why DNS is needed

Names such as www.school-shoes.com are easy to remember. The network needs a number such as 203.0.113.7 to send data to the right server.

What a DNS server stores

A database of domain names and their IP addresses. If it has no record, it asks another DNS server.

Check-in questions with answers

These are the questions behind the Clue Station codes. Answer first, then open the mark points.

Explain 2 marks Why does DNS server 1 store the IP address it receives from DNS server 2?

1. So it can answer the next request for the same domain itself.

2. This is faster and avoids asking another DNS server again.

Explain 2 marks What is the difference between a DNS server and the website server?

1. A DNS server stores domain names and their IP addresses and returns an IP address.

2. The website server stores the website's files and sends them to the browser.

Explain 2 marks Why does a computer need DNS to translate a URL into an IP address?

1. Devices on a network are found by IP address, not by name.

2. DNS gives the computer the number it needs to contact the server.

State 2 marks What does the browser do once it receives the HTML files?

1. It renders (interprets) the HTML.

2. It displays the web page on the screen.

Explain 2 marks Why does the computer need an IP address before it can contact the website server?

1. The IP address identifies where the web server is on the network.

2. Data (the request) can only be sent to the right device if it is addressed to it.

State 2 marks What does the website server send back once it receives the request?

1. The HTML files (and other files such as images) for the page.

2. They are sent to the computer's IP address.

Top tips

  • DNS returns an IP address. It does not send the web page.
  • Use the words "domain name" and "IP address" rather than "the address".
  • Mention caching when a DNS server stores a record it was given.
  • Say what happens if no record exists: an error such as "server not found".
