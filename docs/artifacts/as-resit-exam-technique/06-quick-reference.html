Paper 2 Desk Reference

Keep this next to you every time you practice a question

Step 1 — Before writing anything
Circle the command word. Circle any ALL / ALWAYS / EVERY / ONLY. Circle the exact subject (which firm, market, economy, group).
Step 2 — Apply it (in every paragraph, not one "context" paragraph)
Extract given: use its key terms; do something with every number you quote (% change, comparison, PED); link two sources in one sentence; then go beyond it: industry, product type, stakeholders, place and time.
No extract: write "Case: ..." at the top of your plan and carry it through. Name the stakeholders, use product features, use labelled hypothetical numbers, label diagrams for your case. A real example is optional, and a wrong one is marked down.
Test: could this sentence appear unchanged in an answer about a different market? If yes, add the detail.
Step 3 — 12-mark shape
Optional 1–2 line opener (scope only) → Analysis FOR → Analysis AGAINST → Evaluation paragraph (two CIT blocks, then weigh) → Conclusion (Answer / Because / Unless). Discuss = both sides equal. Evaluate / To what extent = shorter analysis, longer evaluation.
CommandNeeds
Define/StateFact only
ExplainMechanism, step by step
AnalyseExplain + chain of consequences
DiscussBoth sides, developed, judged
Evaluate/ExtentJudgement with conditions
If question says...You must...
ALL / EVERYFind a case it does NOT hold
ALWAYSFind the condition it fails
ONLYShow another cause exists
Names a country, firm or goodAnalyse THAT one throughout
Step 4 — Evaluation: use CIT, with the condition made specific to the case
Condition it depends on → If that condition holds → Then this outcome, because [mechanism]. Do it twice (two conditions), then judge which is more likely/significant for this specific case.
Step 5 — Five evaluation levers (pick one if stuck)
Magnitude  |  Time (short-run vs long-run)  |  Elasticity  |  Type of economy/market  |  Trade-off (who gains, who loses)
Step 6 — Final sentence must
Use the exact wording from the question. State which side wins and under what condition. Never end on "it depends" with nothing after it.
Before you hand it in — 10 second check
Did I answer the command word given, not the topic in general?
If the question said ALL/ALWAYS, did I show an exception?
Did every evaluation sentence name a condition, not just repeat my explanation?
Does my last sentence use the question's own words?
If there was an extract, did I do something with every number I quoted?
Is there a named case, extract figure or stakeholder in every paragraph?
