Binary Search Tree Walkthrough

A binary search tree keeps every node's left subtree smaller and its right subtree bigger. Both insert and search run the same logic: start at the root, compare, and step left or right — insert stops at an empty spot and plants a node there, search stops when it finds a match or runs off the tree into None.

Tree traversals

    
Each traversal visits every node once. They differ only in when the node is output. In-order on a binary search tree gives the values in ascending order. For this tree the three outputs are: in-order 20 30 40 50 60 70 80, pre-order 50 30 20 40 70 60 80, post-order 20 40 30 60 80 70 50.
