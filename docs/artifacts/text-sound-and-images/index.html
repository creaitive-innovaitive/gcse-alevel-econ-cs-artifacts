Text, Sound and Images

How characters, sound waves and pictures become binary: character sets, sampling, pixels and colour depth, and how each choice changes quality and file size.

The big idea

A computer can only store binary, so every letter, sound and picture has to be turned into numbers first and then into 1s and 0s. Text uses a character set. Sound is sampled. Images are broken into pixels. In each case, more bits mean more accuracy and bigger files.

Text

A character set is every character a computer system can recognise, each with its own unique binary code. When you press a key, its code is stored.

Why Unicode? ASCII cannot represent Chinese, Arabic, Hindi or emoji. Unicode has enough codes for all of them, so text can be shared worldwide. The price is more bits per character, so larger files. The first 128 Unicode codes match ASCII.

Codes run in order

Letters are numbered in sequence, so if you know one code you can work out the rest.

If G is 71, then K is 71 + 4 = 75. A lowercase letter is its uppercase code + 32.

Sound

Real sound is an analogue wave: it can take any value. A computer needs digital values, so the wave is sampled: its height (amplitude) is measured at regular intervals and each measurement is stored as a binary number.

Sample rate

The number of samples taken per second, measured in hertz (Hz). 44,100 Hz means 44,100 samples every second.

Higher: closer to the original, but a larger file.

Sample resolution

The number of bits used to store each sample (also called bit depth). More bits means more possible heights, so each sample is measured more precisely.

Higher: more accurate, but a larger file.

Sound file size

file size (bits) = sample rate × sample resolution × length in seconds

Divide by 8 for bytes. Example: 44,100 Hz × 16 bits × 10 s = 7,056,000 bits = 882,000 bytes.

Images

A bitmap image is a grid of tiny squares called pixels. Each pixel stores one binary number that says which colour it is.

Resolution

The number of pixels, width × height. A 100 × 50 image has 5,000 pixels.

Higher: sharper, more detail, bigger file.

Colour depth

The number of bits per pixel. n bits gives 2ⁿ colours.

Higher: more colours, smoother shading, bigger file.

Colour depth1 bit2 bits4 bits8 bits24 bits
Colours241625616,777,216

Image file size

file size (bits) = width × height × colour depth

Example: 64 × 32 pixels at 4 bits = 2,048 × 4 = 8,192 bits = 1,024 bytes.

The file also holds metadata, such as the width, height and colour depth, so the software knows how to rebuild the picture. File size sums in exam questions usually ignore the metadata unless told otherwise.

Not the same thingResolution is how many pixels. Colour depth is how many bits each pixel uses. Sample rate is how often; sample resolution is how precisely. Keep the pairs apart.

Emoji and Unicode

Every emoji has its own Unicode code, which is why a message can show 😀 on any phone. Most websites use the Unicode encoding UTF-8, so one page can mix English, Arabic and Chinese.

Exam use: the reason ASCII is not enough for global communication, and why Unicode files are bigger.

Phone calls versus CDs

Traditional phone lines sample speech at about 8,000 Hz, enough to understand a voice but dull for music. An audio CD samples at 44,100 Hz with 16 bits per sample. Studio recordings often use 96,000 Hz and 24 bits.

Exam use: an example of a trade-off. Lower sample rate and resolution give smaller files and poorer quality, higher give better quality and larger files.

Streaming quality settings

Music and video apps let you choose "data saver" or "high quality". Higher quality uses more data per second, so it needs a faster connection and costs more of a mobile data allowance.

Exam use: connects file size to download time and storage.

Camera megapixels

A 12-megapixel camera captures roughly 12 million pixels per photo. More pixels allow bigger prints and more zoom before the picture turns blocky, but every photo takes more storage.

Exam use: a real figure for resolution. Use it to explain why higher resolution means bigger files.

GIFs, photos and QR codes

A GIF can show up to 256 colours (8 bits per pixel). A normal photo uses 24 bits per pixel, about 16.7 million colours. A QR code or a black-and-white fax uses only 1 bit per pixel.

Exam use: shows how colour depth is chosen to match the content: only as many bits as needed.

Photo metadata

Besides the pixels, a phone photo stores metadata such as its dimensions, colour depth, the date, and often the camera model and location.

Exam use: an example of metadata. Software needs the width, height and colour depth to rebuild the picture from the bits.

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each underlined phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks What is meant by a character set?
ReminderTwo points: all the characters a system can recognise, and a unique binary code for each.
A character set is all of the characters that a computer system can recognise and use where each character is given a unique binary code.
Common mistakeNaming ASCII without defining what a character set is. ASCII is an example, not the definition.
Q2 Explain 3 marks Unicode needs more storage per character than ASCII. Explain why Unicode is still used.
ReminderTwo uses of Unicode, and the link to the number of codes available.
Unicode uses more bits per character (up to 32), so it has many more codes available (over 140,000). This lets it represent characters from almost every language, as well as symbols and emoji, which ASCII cannot. Text can therefore be shared and displayed correctly across different countries and devices.
Common mistakeSaying "Unicode is better" without a reason. Always link more bits → more characters → more languages.
Q3 Give 2 marks The ASCII code for G is 71. Give the 8-bit binary code for K.
ReminderG, H, I, J, K: count along. Then convert to binary.
K is four letters after G, so 71 + 4 = 75 75 = 01001011
Common mistakeWriting 7 bits, or counting from G as 1 and getting 74.
Q4 Describe 4 marks Describe how a sound is converted into a digital sound file.
ReminderPut the steps in order: analogue wave, sampling at intervals, measure each sample, store as binary.
The sound wave is analogue, and it is sampled by measuring its amplitude (height). The measurements are taken at regular time intervals, a set number of times per second (the sample rate). Each measurement is rounded to the nearest value that can be stored, using a set number of bits (the sample resolution). Each sample is stored as a binary number, and the sequence of binary values makes up the file.
Common mistakeSaying the wave is "converted to binary" in one step with no mention of sampling or intervals.
Q5 Describe 3 marks The sample rate of a recording is increased. Describe the effect on the sound quality and the file size.
ReminderQuality and file size both need a statement. Say why.
More samples are taken each second, so the digital sound is closer to the original wave. The quality is therefore higher (more accurate). More samples are stored, so the file size increases.
Common mistakeMixing up sample rate and sample resolution. Rate is how often; resolution is how many bits per sample.
Q6 Calculate 3 marks A bitmap image is 100 pixels wide and 50 pixels high. Each pixel uses 8 bits. Calculate the file size in bytes. Ignore metadata.
ReminderPixels × bits per pixel gives bits. Divide by 8 for bytes.
100 × 50 = 5,000 pixels 5,000 × 8 = 40,000 bits 40,000 ÷ 8 = 5,000 bytes
Common mistakeStopping at 40,000, which is in bits. The question asks for bytes.
Q7 Explain 4 marks Explain how a bitmap image is stored in a file, and why the file needs metadata.
ReminderPixels, a binary value for each, and then what the metadata contains and what it is for.
The image is divided into a grid of pixels. Each pixel is stored as a binary number that represents its colour, using the colour depth (bits per pixel). The file holds metadata, such as the width, height and colour depth of the image, so the software knows how to split the stream of bits back into pixels and rebuild the picture correctly.
Common mistakeDescribing metadata as "the image data". Metadata is data about the image.
Q8 Explain 4 marks A music app offers two options: 44,100 Hz with 16-bit samples, or 8,000 Hz with 8-bit samples. Explain the benefits of each.
ReminderTwo benefits for each option, using rate and resolution.
44,100 Hz takes many more samples per second, so the sound is closer to the original. 16 bits per sample allows more levels, so each sample is more accurate. The 8,000 Hz, 8-bit option has far fewer bits per second, so the file is much smaller. It uses less storage and downloads or streams faster, though with lower quality.
Common mistakeOnly describing one option. "Benefits of each" needs a point for both.

Top tips

  • Define before you name. A character set is all the characters a system can use, each with a unique code. ASCII and Unicode are examples.
  • Unicode answers need the chain: more bits, more codes, more languages and symbols, bigger files.
  • Use the order of the codes. Count along from the code you are given.
  • Sound: two settings. Sample rate is how often, sample resolution is how many bits each. Both raise quality and file size.
  • Images: two settings. Resolution is how many pixels, colour depth is how many bits each.
  • File sizes: multiply everything, then ÷ 8 for bytes. Say "bits" or "bytes" in your answer.
  • Show each step of a calculation. You can earn marks even if the final answer slips.
  • Metadata is data about the file (width, height, colour depth), not the picture itself.
