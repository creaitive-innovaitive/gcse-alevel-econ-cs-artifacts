Cyber security

The threats to data and computer systems, and the measures that stop them. Learn it, watch it happen, practise it, then answer exam questions.

Threats

Each threat is a way of stealing, damaging or blocking access to data or systems. In the exam, name the threat, say how it works, then say what it does.

Defences

Every defence should be linked to a threat and a mechanism. "It keeps you safe" earns nothing.

Top tips

    Command words you will meet

    State / Identify / Give
    A short answer. One fact, no reason needed.
    Describe
    Say what happens or what it is like. Several facts in order.
    Explain
    Give a point and a reason: "because", "so that", "which means".
    Discuss
    Advantages and disadvantages, then a judgement.

    See it work

    Pick a scenario and step through it. Red packets are attacks, teal ones are protection at work.

    Slider lab: DDoS attack

    The server can handle 100 requests a second. Genuine users send 10. Each infected computer (bot) adds 1 more. Drag the slider to see when genuine users get shut out.

    Exam link: a DoS attack comes from one computer. DDoS is distributed: many computers, usually a botnet the attacker controls. Say "many" and "at the same time".

    Slider lab: brute-force attack

    A brute-force attack tries every combination. Change the password length and the characters allowed, and watch the time to crack it.

    Exam link: longer and more varied passwords mean more combinations, so it takes longer. Limiting login attempts and 2FA stop the attack from working even if the password is guessed.
