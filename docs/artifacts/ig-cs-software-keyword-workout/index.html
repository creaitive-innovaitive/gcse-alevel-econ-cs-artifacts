Software: Keyword Workout

Types of software, translators and errors: learn the keywords, watch a compiler and an interpreter handle an error, then work through the printable worksheet.

The big idea

Software is a set of instructions. System software runs the computer (the operating system and utilities). Application software does jobs for the user. Programs written by people must be translated into machine code before the processor can run them.

TermMeaning
Operating systemManages hardware, memory and files so applications can run. Provides a user interface.
Utility softwareHousekeeping software such as anti-virus, defragmentation, compression and backup.
Application softwareSoftware for users' tasks: word processors, browsers, games and spreadsheets.
Bespoke softwareWritten to one customer's requirements. Off-the-shelf software is made for many customers.
FirmwarePermanent software stored on a ROM chip inside a device.
Source codeCode as typed by the programmer, before translation.
CompilerTranslates the whole high-level program into machine code before it runs.
InterpreterTranslates and runs a high-level program line by line, stopping at the first error.
IDEOne package with an editor, translator and debugger.

Syntax error

A mistake in the rules of the language. The program cannot run at all.

Logic error

The program runs but gives the wrong result, because the steps are wrong.

Exam-style questions

Write your answer first, then open the mark points. Tick the ones you earned.

Q1 Describe 3 marks Describe three functions of an operating system.

Any three from: provides a user interface; manages memory; manages files; manages peripherals and their drivers; manages user accounts and security; allows multi-tasking.

Common mistakeListing names only. Say what each one does.
Q2 Explain 2 marks Explain one difference between a compiler and an interpreter.

1. A compiler translates the whole program before it runs, producing machine code (object code); an interpreter translates and runs one line at a time.

2. An interpreter stops at the first error; a compiler reports errors after translating the whole program.

Q3 Explain 2 marks Explain the difference between a syntax error and a logic error.

1. A syntax error breaks the rules of the language, so the program cannot run.

2. A logic error lets the program run but produces the wrong output.

Top tips

  • Say what the operating system does, not just that it "runs the computer".
  • Utility versus application. Utilities look after the computer; applications do the user's tasks.
  • Compiler versus interpreter: whole program first, or line by line.
  • Syntax versus logic. A syntax error stops the program; a logic error gives wrong results.
  • Source code is translated into machine (object) code before the processor can run it.
