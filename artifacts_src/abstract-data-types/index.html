Abstract Data Types: Stacks, Queues, Linked Lists, Trees and Graphs

An abstract data type is defined by what you can do with it, not by how it is stored. Watch each ADT work step by step on arrays (graphs are covered in their own section and a separate explainer), operate your own, and practise the trace and pseudocode questions.

The big idea

An abstract data type (ADT) is a collection of data together with the operations that can be performed on it. It describes what you can do (push, pop, insert, delete) and hides how the data is stored. The same ADT can be built from an array, from records and pointers, or from another ADT (see 19.1.4).

Stack

Last in, first out (LIFO). Items are added and removed at the same end, the top.

Operations

push, pop, peek, isEmpty, isFull

Pointer

Top of stack

Queue

First in, first out (FIFO). Add at the rear, remove from the front.

Operations

enqueue, dequeue, isEmpty, isFull

Pointers

Front and rear (plus a count if circular)

Linked list

A chain of nodes, each holding data and a pointer to the next node. Order is held by the pointers, not by position.

Operations

traverse, insert, delete, search

Pointers

Start pointer, null pointer, free-list pointer

Binary tree

Each node has at most two children: left and right. In a binary search tree, smaller values go left, larger go right.

Operations

insert, search, traverse (pre, in, post)

Pointers

Root, left and right pointers

Graph

Vertices joined by edges, with no fixed shape. Edges may be directed or weighted. Models maps and networks.

Operations

add vertex, add edge, find neighbours, shortest path

Stored as

Adjacency matrix or adjacency list

Stack

Think of a pile of plates. You can only add to or take from the top. Using an array with a top-of-stack pointer that starts at −1 when empty:

OperationWhat it doesCheck first
push(item)Add 1 to the pointer, store the item thereStack full: pointer = MaxSize − 1
pop()Read the item at the pointer, subtract 1 from the pointer, return the itemStack empty: pointer = −1
peek()Read the top item without removing itStack empty

Queue

A queue at a shop till. In a linear queue, the front pointer moves along as items leave, so space at the start of the array is wasted. A circular queue reuses that space by wrapping the pointers round with MOD MaxSize.

OperationWhat it doesCheck first
enqueue(item)Rear ← (Rear + 1) MOD MaxSize, store the item, count + 1Queue full: count = MaxSize
dequeue()Read the item at Front, Front ← (Front + 1) MOD MaxSize, count − 1Queue empty: count = 0

Linked list

Instead of items sitting next to each other, each node says where the next one is. Using two parallel arrays, Data and Pointer, a pointer of −1 means null (the end). Unused nodes are chained into a free list, so a new node is taken from the front of the free list and a deleted node is returned to it.

Insert

Take a node from the free list, store the data, find the node that should come before it, then change two pointers: the new node points on to what followed, and the previous node points to the new node. Nothing is shifted.

Delete

Find the node and the one before it. Make the previous node point to the deleted node's successor. Then return the deleted node to the free list. If it was the first node, move the start pointer instead.

Binary tree

The first node is the root. A node with no children is a leaf. To insert into a binary search tree, start at the root and go left if the new value is smaller or right if it is larger, until you reach an empty place.

TraversalOrder of visitingUse
Pre-orderNode, then left subtree, then right subtreeCopying a tree
In-orderLeft subtree, then node, then right subtreeOutputs a binary search tree in sorted order
Post-orderLeft subtree, then right subtree, then nodeDeleting a tree; evaluating expressions (Reverse Polish)

Graph

A graph is a set of vertices (nodes) joined by edges (arcs). Unlike a tree, it has no root and may contain cycles, so any vertex can connect to any other. Edges can be directed (one-way, drawn as arrows) and weighted (carrying a distance, time or cost). It can be implemented as an adjacency matrix (a 2D array with a 1 or the weight where an edge exists) or an adjacency list (a list of neighbours for each vertex).

5 · Multiple choice

Descriptions are kept general. Use them as examples of ideas, not as exact descriptions of any company's software.

Undo in a text editor (stack)

Each edit is pushed onto a stack. Pressing undo pops the most recent edit and reverses it. A redo stack holds the edits you have undone.

Exam use: the standard LIFO example. The last action done is the first undone.

The browser back button (stack)

Each page you visit is pushed. Back pops the current page and shows the previous one.

Exam use: another LIFO example, with a clear push and pop.

Function calls (stack)

When one subroutine calls another, the return address and local variables are pushed onto the call stack, and popped when the subroutine finishes. Too many nested calls causes a stack overflow.

Exam use: why recursion needs a stack, and what "stack full" means in practice.

Print queue (queue)

Documents are printed in the order they were sent. New jobs join the rear; the printer takes from the front.

Exam use: the standard FIFO example.

Keyboard buffer (circular queue)

Keypresses wait in a small fixed buffer until the program reads them in order. A fixed-size buffer that reuses its space is a circular queue.

Exam use: why a circular queue suits a fixed-size memory area: the pointers wrap round instead of the data moving.

A playlist of songs (linked list)

Each track knows which track plays next. Adding a track to the middle only changes where two tracks point; nothing else moves.

Exam use: why a linked list makes insertion and deletion cheap compared with shifting array items.

Maps and social networks (graph)

Junctions are vertices and roads are weighted edges, so a satnav can find the shortest route. In a social network, people are vertices and friendships are edges.

Exam use: say what the vertices, edges and weights represent. A huge sparse graph like this suits an adjacency list.

Folders on a computer (tree)

A folder contains files and other folders, forming a tree from the root. Searching or listing everything means traversing the tree. (File systems are general trees, not always binary.)

Exam use: a real hierarchy. Mention that a binary tree restricts each node to two children.

Sorted data with fast lookup (binary search tree)

A program that keeps names in a binary search tree can find one by comparing with the root and going left or right, discarding about half of the remaining tree each time if the tree is balanced.

Exam use: an in-order traversal gives the names alphabetically; link back to binary search (19.1.1).

Exam-style questions

Open each question for reminders, a model answer and common mistakes. Each coloured phrase earns one mark; the number shows which mark point it is.

Q1 State 2 marks State two features of a stack.
ReminderLIFO plus where items are added and removed.
It is a last in, first out (LIFO) data structure. Items are added (pushed) and removed (popped) at the same end, the top, which is tracked by a pointer.
Common mistakeMixing up LIFO and FIFO. A stack is LIFO; a queue is FIFO.
Q2 Describe 3 marks Describe how an item is added to a stack that is stored in an array.
ReminderCheck, move the pointer, store.
Check whether the stack is full (top pointer equals the maximum index); if it is, the item cannot be added. Otherwise add 1 to the top-of-stack pointer. Store the new item in the array at the position of the pointer.
Common mistakeStoring the item before incrementing the pointer, which overwrites the current top.

Q4 Explain 3 marks Explain why a circular queue is better than a linear queue when it is stored in an array of fixed size.
ReminderWhat goes wrong with the linear version, and what the circular version does about it.
In a linear queue, as items are removed from the front, the space at the start of the array is never reused, so the queue can appear full while there is spare space. In a circular queue, when the rear pointer reaches the end of the array it wraps round to the start (using MOD). So the freed space is reused and the fixed memory is used efficiently, without shifting items.
Common mistakeSaying a circular queue "has no end". It still has a fixed maximum size; it can still become full.

Q6 Describe 4 marks Describe how an item is deleted from the middle of a linked list stored in arrays.
ReminderFind it, bypass it, and recycle the node.
Follow the pointers from the start pointer, keeping track of the previous node, until the item to delete is found. Set the previous node's pointer to the pointer of the node being deleted, so the list bypasses it. Set the deleted node's pointer to the current free-list pointer. Set the free-list pointer to the deleted node, so it can be reused.
Common mistakeSaying the later items are "moved up". Linked lists change pointers; nothing moves.
Q7 Complete 3 marks Values 50, 30, 70, 20, 40, 60 are inserted into an empty binary search tree in that order. Give the output of each traversal.
ReminderSketch the tree first: 50 at the root, 30 and 70 below, then 20 and 40 under 30, 60 under 70 (left).

Pre-order (node, left, right): 50, 30, 20, 40, 70, 60

In-order (left, node, right): 20, 30, 40, 50, 60, 70

Post-order (left, right, node): 20, 40, 30, 60, 70, 50

Common mistakeReading the tree level by level. That is breadth-first, not one of the three required traversals.
Q8 Explain 4 marks A program keeps an ordered list that is often changed by adding and removing items in the middle. Explain why a linked list may be more suitable than an array.
ReminderGive the advantage, the reason, and one drawback to balance.
In an array, inserting or deleting in the middle means shifting many items along to make or close a gap, which is slow for large lists. In a linked list only one or two pointers need to change, and no other item moves. A linked list can also grow and shrink as needed by using free nodes. However, each node needs extra memory for its pointer, and items cannot be reached directly by index, so searching needs a traversal from the start.
Common mistakeSaying linked lists are "faster". They are faster for insertion and deletion, but slower for direct access.
Q9 Write 5 marks A stack is stored in the array Stack with the pointer TopPointer (−1 when empty) and MaxSize items. Write a function Pop that returns the top item, or outputs "Stack empty" if there is none. Use Python or pseudocode.
ReminderEmpty check, read the item, move the pointer down, return.
def pop():
    global top
    if top == -1:                  # (1) test for empty
        print("Stack empty")       # (2) message
    else:
        item = stack[top]          # (3) read the top item
        top -= 1                   # (4) pointer moves down
        return item                # (5) return the item

Test top = −1. Output the message in that case. Read the item at the top pointer. Subtract 1 from the pointer. Return the item.

Common mistakeDecrementing the pointer before reading the item, which returns the wrong value.
Q10 Describe 4 marks Describe what is meant by a graph, and explain how a graph could be stored in a program. (See the Graphs explainer for Dijkstra's algorithm and more.)
ReminderDefine it, mention direction and weights, then name two ways to store it.
A graph is an abstract data type made up of vertices (nodes) joined by edges (arcs). Edges can be directed (one-way) and can have weights, such as a distance. It can be stored as an adjacency matrix, a 2D array with a 1 or the weight in row r, column c if there is an edge from r to c. Or it can be stored as an adjacency list, where each vertex has a list of the vertices it is joined to.
Common mistakeConfusing a graph with a tree. A tree is a connected graph with no cycles and a root.

Top tips

  • Define an ADT by its operations. It is the data plus what you can do with it, with the storage hidden.
  • Stack = LIFO, queue = FIFO. Say the full name and give a real example.
  • Check first, then change. Full before push, empty before pop, in the same order as the code.
  • Draw the structure. For any trace, sketch the array after every operation. Marks follow the sketch.
  • Circular queues use MOD. (Rear + 1) MOD MaxSize. It can still become full.
  • Linked lists change pointers, not positions. Insert: new node points on, previous points to new. Delete: previous bypasses. Return the node to the free list.
  • Mind the free pointer. Forgetting to update it is the commonest lost mark in linked-list tables.
  • Graphs: name the vertices, edges and weights. Row is from, column is to in a matrix. Sparse graph, use a list.
  • Tree traversals have a word order. Pre = node first, in = node in the middle, post = node last. In-order of a binary search tree is sorted.
  • Check array bounds. This artifact starts at 0 with top = −1 for empty. Many CIE questions start at 1.
